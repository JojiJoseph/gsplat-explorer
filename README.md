# GSPLAT EXPLORER

This is a tool for exploring Gaussian Splats.

# How to run

```bash
python view.py --input_path path/to/ply --format ply
```

Supported formats are .ply, .pth (inria), .pth (gsplat)

The checkpoint can be obtained with https://github.com/graphdeco-inria/gaussian-splatting


Click [here](https://drive.google.com/file/d/1cAOhitE3u8ADUR0X6-14VmVzafnyerti/view?usp=sharing) to download a sample checkpoint.
